# Humanity OS v0.1 — Public Release

Humanity OS is a nonviolent, democratic, open-source constitutional protocol for human dignity, accountable power, intergenerational justice, basic security, and coexistence among humans, artificial intelligence, other sentient beings, and the living world.

This public release is based on the uploaded **Humanity OS v0.1 — Constitution** dated 2026-10-23. The original constitutional content has been preserved. The only substantive addition to the constitution is the **Language Equality Principle**.

## Core Kernel

- Dignity
- Equality Before Law
- Transparency
- Intergenerational Justice
- Basic Security
- Coexistence

## Language Equality Principle

No language is the language of authority. Translations are not subordinate versions. Where meanings diverge, the divergence must be documented, disclosed, discussed, and resolved transparently.

The Japanese source edition and the English Reference Edition are intended to function as equal reference editions. The Japanese–English Complete Parallel Reference Edition places the source and translation together for direct review.

## How to Participate

Read it. Critique it. Test it. Translate it. Fork it. Improve it.

Participation does not require agreement. Substantive criticism, counter-evidence, alternative institutional designs, translations, accessibility improvements, and documented forks are welcome.

Humanity OS explicitly rejects violence, terrorism, indiscriminate destruction, persecution, forced conversion, and collective retaliation as means of institutional change. Development and adoption should proceed through peaceful, democratic, lawful, and auditable processes.
