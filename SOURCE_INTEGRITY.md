# SOURCE INTEGRITY

The source for this release is the uploaded **Humanity OS v0.1 — Constitution**, dated 2026-10-23.

The Japanese constitutional text has been preserved without rewriting, summarization, policy expansion, or silent correction. The requested **Language Equality Principle / 言語平等原則** has been inserted as a new standalone section immediately after the Public Commitment and before the Fork Header.

The English Reference Edition is a full translation intended to read naturally as an international constitutional charter while preserving the source document's structure, normative force, uncertainty, and distinctions.

The Japanese–English Complete Parallel Reference Edition is provided for direct comparison and translation audit.
